\# Distributed Hash Cracker - Parallel and Distributed Computing



\## Project Overview



This project implements a hash cracking system using three parallel computing paradigms:

1\. \*\*Serial Baseline\*\* - Single-threaded implementation for performance comparison

2\. \*\*OpenMP\*\* - Shared-memory parallelism using multi-core CPU

3\. \*\*OpenCL\*\* - Parallel computing on CPU/GPU (placeholder implementation)

4\. \*\*Cloud Distributed\*\* - gRPC-based distributed system with 1 coordinator + 3 workers on Google Cloud Platform



Target: Crack SHA256 hash of "admin" using dictionary attack
